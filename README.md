Плагин к **Astra** от **Voltur**: живая фоторамка на рабочем столе. Показывает выбранные папки с фото и видео как слайдшоу плиткой на домашнем экране Astra (`desktop.widget`): с анимацией смены кадра, стилями паспарту, подписями и любым размером — рамку тянут за край сетки. Работает без сети: кадры идут с вашего диска. Нужны Astra 0.2.7 или новее и 64-разрядный Python 3.10 или новее.

## Что нужно один раз настроить

1. **Поставить рамку на рабочий стол.** На домашнем экране Astra — «Панель виджетов» → «Фоторамка». Плитка появляется в сетке; размер меняется тяжением за край (от 2×2 до 12×8 клеток). Рамку можно поставить в несколько мест стола — у каждой копии свои настройки.
2. **Выбрать папки с кадрами.** У плитки — «Настройки рамки»: «📁 Выбор папки…» открывает привычное окно Windows, где можно выбрать папку переходом по дереву. Можно добавить несколько папок — до 12; рамка листает их как общий альбом. Если диалога нет (не Windows) — «Ввести путь вручную». Кнопка «Проверить» показывает, сколько кадров рамка видит на самом деле, и подсказывает, если путь недоступен.
3. **Настроить показ** — не обязательно, по умолчанию всё настроено разумно: интервал смены от 2 секунд до часа, порядок (перемешивать или как на диске), переходы (плавный, слайд, «зум и панорама» — эффект Кена Бёрнса — или без анимации), фон рамки (стеклянное паспарту, прозрачная, тёмная, белая, «галерея с тенью»), поле и скругление, подпись (имя файла, дата снимка или часы поверх кадра), поведение видео (один раз или по кругу).

## Возможности

- Фото: jpg, png, webp, gif (анимированные — без пержатия), bmp; видео: mp4, webm, mov. Свой список кадров у каждой копии рамки.
- Подпапки — отдельной настройкой «искать в подпапках».
- Кадр не меняется, пока следующий не готов: пауз и пустых экранов между переходами нет — новый кадр догружается заранее, а предзагружается уже следующий за ним.
- Тяжёлые кадры не грузятся целиком в память плитки: сначала отдаётся быстрый вариант для предпросмотра, потом — полный под размер рамки. Готовые кадры кэшируются, и повторная смена того же кадра мгновенная.
- Настройки хранятся внутри плитки Astra, не в файлах плагина: переустановка рамки их не сбрасывает.

## Вне сети и запасные пути

Плагин не ходит в интернет вовсе. Кадры он раздаёт плитке через локальный поток `127.0.0.1` (для видео — с докачкой по диапазону, как у стримов). Если хост блокирует этот поток (так бывает из-за настроек безопасности окна), рамка сама уходит в мост Astra и передаёт кадр через него — медленнее, но работает; отличить одно от другого можно по логу плагина.

## Если что-то не так

| В логе или на рамке | Что делать |
| --- | --- |
| «Папки не найдены: …» | Путь недоступен: диск съёмный, сетевой или удалён. Откройте «Настройки рамки» и замените папку. |
| «Папок пока нет — добавьте хотя бы одну» | В настройках рамки нет ни одной папки — нажмите «📁 Выбор папки…» или «Ввести путь вручную». |
| «Кадр не найден: обновите список» | Список устарел после изменения папок — обновите рамку кнопкой ⟳ на плитке. |
| «Выбор папки кликом доступен в Windows — путь можно ввести вручную» | Это не Windows: нативного диалога нет — введите путь вручную. |
| «Ни один файл не загрузился — проверьте папки» | Ни один выбранный файл не открылся: проверьте «Проверить» в настройках. |
| Кадры меняются медленно при первом открытии | Первое сканирование и подготовка тяжёлых папок долгие: дальше включается кеш, должно стать быстрее. |

## Требования, установка и проверка

- Windows x64 — основное устройство (нативный выбор папки); Linux x64 и macOS — эксперимент, без нативного диалога; venv ставится из `requirements.lock`, нужен 64-разрядный Python 3.10+.
- Локально: клонируете папку — `git clone`, в Astra Plugins → Dev → «Загрузить папку», на рабочем столе «Добавить виджет» → «Фоторамка».
- Проверки перед правкой: `pytest` (скан, кеш, поток, формат ответов), `node scripts/ui-check.js` — браузерный стенд плитки и настроек, `astra-plugin check . --strict` и `astra-plugin test .` (conformance).
